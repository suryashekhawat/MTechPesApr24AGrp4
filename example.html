Code Examples

Basic Usage

// Find the most similar element const bestMatch = findMostSimilarElement('#submit-btn'); if (bestMatch) { highlightElement(bestMatch, 'red', 3000); bestMatch.click(); }

Advanced Usage with Options

// Find similar elements with custom options const similarElements = findSimilarElements('#submit-btn', { maxResults: 5, minScore: 3, excludeSelectors: ['.hidden', '.disabled'], includeHidden: false }); similarElements.forEach(({element, score}) => { console.log(`Element: ${element.tagName}, Score: ${score}`); highlightElement(element, 'blue', 2000); });

Using the Similo Class

// Create a Similo instance with custom configuration const similo = new Similo({ minScore: 2, maxCandidates: 500, weights: { TAG_NAME: 4, ID: 6, CLASS: 3 } }); // Find similar elements const result = similo.find('#submit-btn'); if (result) { highlightElement(result, 'green', 3000); }

API Reference

Functions

findMostSimilarElement(sourceSelector, options)

Finds the most similar element to the source element.

  • sourceSelector: CSS selector string or Element object
  • options: Configuration object (optional)
  • Returns: Element or null

findSimilarElements(sourceSelector, options)

Finds multiple similar elements, sorted by similarity score.

  • sourceSelector: CSS selector string or Element object
  • options: Configuration object (optional)
  • Returns: Array of {element, score} objects

highlightElement(element, color, duration)

Highlights an element for debugging purposes.

  • element: DOM element to highlight
  • color: Highlight color (default: 'red')
  • duration: Duration in milliseconds (default: 3000)

Options

  • minScore: Minimum similarity score (default: 0)
  • maxCandidates: Maximum number of candidates to check (default: 1000)
  • excludeSelectors: Array of CSS selectors to exclude (default: [])
  • includeHidden: Include hidden elements (default: false)
  • maxResults: Maximum number of results to return (for findSimilarElements)

Similarity Weights

  • TAG_NAME: 3 points
  • ID: 5 points
  • CLASS: 2 points per common class
  • TEXT_CONTENT: 4 points (exact match)
  • TEXT_PARTIAL: 2 points (partial match)
  • NAME_ATTR: 3 points
  • PLACEHOLDER: 2 points
  • ARIA_LABEL: 3 points
  • ARIA_DESCRIBEDBY: 3 points
  • POSITION: 1 point (within 100px)
  • VISIBLE: 1 point
  • INTERACTIVE: 2 points
